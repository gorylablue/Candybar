# Candy Bar Exotic Drinks: propuesta de En El Mapa

Página de una sola pieza (`index.html`, sin build) para Candy Bar Exotic Drinks, Calle Estrella esq. León #84, Ponce.
En vivo: https://candybar-ponce.netlify.app

## Ramas
- `trabajo`: avances. No gasta créditos de Netlify.
- `main`: lo que se publica. Solo con aprobación del usuario ("publícalo").

- v1 completa: letrero de bombillas (Canvas), trago servido en vivo con "Sírveme otro" (SVG + `render(t)`), 11 shotsitos reales, neón letra por letra, Celebra en Candy Bar (vela + "Planifica tu noche" que copia el mensaje y abre el DM de Instagram), opiniones, horario en vivo (hora de PR, vie y sáb hasta 3 a.m.), mapa ilustrado, barra fija en iPhone.
